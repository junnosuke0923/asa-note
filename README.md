# きそたいおん

毎朝の基礎体温を、やさしく記録するアプリ。

スマホでは、ここから直接ひらけます（ホーム画面に追加すると、アイコンから起動できます）。
→ https://junnosuke0923.github.io/asa-note/

パソコンでの使いかたは [はじめにお読みください.txt](はじめにお読みください.txt) を見てください。
番号のついた `.bat` をダブルクリックするだけで開きます。

## 開発者向けのメモ

### 動かす

| コマンド | すること |
| --- | --- |
| `npm run dev` | 開発モード（絵とことばの編集画面つき） |
| `npm run build` | 本番用に組み立てる |
| `npm run preview` | 組み立てたものを確認する |
| `npm run lint` | 書き方の点検 |
| `node scripts/bundle-artifact.mjs` | 1枚のHTMLにまとめる（Artifact公開用） |
| `npm run deploy` | 今のコードを、スマホ用の公開URLに反映する |

### 設計のメモ

- **通信しない** — 記録はすべて端末の中（LocalStorage / IndexedDB）。
  外部に送る処理は一切書かない。同期フォルダへの書き出しは
  ローカルのファイル書き込みで、同期はOS側の同期ソフトが行う。
- **絵とことば** — `src/data/appAssets.js` に焼きこまれる。
  このファイルは開発モードの編集画面から自動生成される（手で書いてもよい）。
  編集画面は `import.meta.env.DEV` で囲ってあり、本番ビルドには含まれない。
- **色** — `src/index.css` の `@theme` で名前をつけ、
  暗いモードは同じ名前の中身だけ差し替える。各画面は色の出し分けを知らない。
- **日付キー** — `"YYYY-MM-DD"` の文字列。`toISOString()` は使わない
  （世界標準時に変換されて、朝の記録が前日扱いになるため）。
- **周期の判定** — 月経日から導く。開始日を別に持たせると矛盾した
  データが作れてしまうため。記録漏れに備え、10日以内に続く月経日は
  同じ月経の続きとみなす。
- **高温期の境目** — 36.7℃固定ではなく、その人の低温期平均から算出する。

### 主なフォルダ

```
src/
  components/   画面と部品
  hooks/        保存・通知・自動保存などの仕組み
  lib/          計算（周期・体温・バックアップ・日付）
  data/         文言と、焼きこまれた絵
scripts/        起動用スクリプトと、公開用のまとめ処理
```
